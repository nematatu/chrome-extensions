# バドスピ 高画質画像ダウンローダー

[バドスピ](https://www.badspi.jp/)の画像を元の画質で開き、保存しやすくするChrome / Edge向け拡張機能です。

## 機能

- 画像リンク末尾の `-数字x数字`（例: `-682x430.jpg`）を除き、WordPressの元画像URLへ置換
- ギャラリー画像を新しいタブで開く場合も元画像を表示
- ライトボックス（拡大表示）内の画像を元画像へ置換
- 拡大表示にシンプルなダウンロードアイコンを追加
- 保存場所やファイル名を毎回確認せず、`ダウンロード/badspi` に元画像のファイル名で保存
- 前後の画像へ移動した場合も自動追従

## インストール

1. GitHubの「Code」→「Download ZIP」でダウンロードし、ZIPを展開します。
2. Chromeで `chrome://extensions`（Edgeでは `edge://extensions`）を開きます。
3. 「デベロッパー モード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」を押します。
5. 展開したフォルダーを選択します。
6. 開いているバドスピのページを再読み込みします。

## 対応範囲

`https://www.badspi.jp/wp-content/uploads/` 配下にあるJPEG、PNG、GIF、WebP、AVIF画像を対象にします。元画像ファイルがサーバーに存在しない場合は保存できません。また、サイト側のHTMLやライトボックスの仕様変更時には調整が必要になる可能性があります。

## テスト

Node.js 18以降で実行できます。

```sh
node --test quality-core.test.cjs
```
