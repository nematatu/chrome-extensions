# Media Saver

ページ上の動画・音声・画像を検出し、ブラウザー内で保存する Manifest V3 拡張機能です。
HLS（`.m3u8`）は VOD を MP4/M4A に結合し、DASH（`.mpd`）は映像と音声を別ファイルとして保存します。

> この拡張機能は独立したクリーンルーム実装です。他社製ダウンローダーのコード、UI、画像素材は使用していません。
> DRM の回避やライブ配信の保存は行いません。保存する権利があるコンテンツのみ、個人利用の範囲で使用してください。

このリポジトリの My Tools には「Media Saver」として同梱されています。My Tools から使う場合も、このディレクトリの単独版と同じ検出・保存処理を利用します。My Tools と単独版は保存領域が別です。

## 主な機能

- ネットワーク通信とページ内 DOM の両方からメディアを検出
- 動画 / 音声 / 画像の絞り込み、複数選択、一括保存
- HLS / DASH の画質一覧を取得し、保存する画質を選択
- ダウンロードキュー（同時実行数 1〜6）と進捗・履歴表示
- ツールバーバッジに検出件数を表示
- ライト / ダーク / システム連動テーマ
- 保存フォルダー、ファイル名テンプレート、除外ドメインなどの設定
- 検出した URL やページ内容を外部サーバーへ送信しないローカル処理

## インストール

1. Chrome 116 以上を用意します。
2. `chrome://extensions` を開きます。
3. 右上の「デベロッパー モード」を有効にします。
4. 「パッケージ化されていない拡張機能を読み込む」を選び、この `media-saver` ディレクトリを指定します。
5. ツールバーの Media Saver アイコンをピン留めします。

拡張機能を更新した後は、`chrome://extensions` の再読み込みボタンを押し、対象ページも再読み込みしてください。

## 使い方

1. メディアのあるページを開きます。
2. HLS / DASH は、ページ上で動画の再生を開始します。直接ファイルの URL は再生前でも検出できます。
3. ツールバーのアイコンを開きます。必要なら右上の再スキャンボタンを押します。
4. 種類フィルターで絞り込み、保存するメディアを選びます。
5. HLS / DASH では画質を選べます。「自動（最高画質）」が初期値です。
6. カードの保存ボタン、または「選択を保存」でダウンロードを開始します。一度に保存できるのは、一覧の上限と同じ300件までです。
7. 「ダウンロード」タブで進捗、完了、失敗理由を確認できます。

### 検出について

- 直接の MP4 / WebM / MP3 / 画像などは、通信またはページ内の要素から検出します。
- HLS / DASH は、プレイヤーがマニフェストを取得したタイミングで検出します。ページを開いただけでは検出されない場合があります。
- インストール直後や拡張機能の再読み込み後は、ページを再読み込みしてから再生し直してください。
- `chrome://`、Chrome ウェブストア、一部の保護されたページではページ内スキャンができません。その場合は通信から検出できたものだけを表示します。
- バッジと一覧の件数は、設定で無効にした種類、除外ドメイン、最小サイズを反映します。

## 対応形式

| 種類 | 検出・保存の内容 |
| --- | --- |
| 直接ファイル | MP4 / WebM / MOV / MKV などの動画、MP3 / M4A / AAC / OGG / WAV / FLAC などの音声、JPEG / PNG / WebP / GIF / AVIF / BMP 画像を元の形式のまま保存 |
| HLS | 暗号化されていない VOD の `.m3u8`。MPEG-TS は MP4 に結合、fMP4 は init + セグメントを連結。音声のみの HLS は M4A |
| DASH | 暗号化されていない静的 MPD。SegmentTemplate（Number / Timeline）、SegmentList、SegmentBase / 単一ファイルに対応。映像 MP4 と音声 M4A を別々に保存 |
| 画像ギャラリー | `img`、`srcset`、`picture`、画像へのリンク、OGP 画像など。極端に小さい画像や SVG は除外 |

HLS の音声が別トラック（`EXT-X-MEDIA`）で、映像に音声が含まれず、映像・音声とも MPEG-TS の場合は 1 つの MP4 に結合します。
映像または音声が fMP4 の分離 HLS、複数期間の DASH、再生リスト外の字幕・広告トラックには対応しません。

## 対応範囲外

- DRM / ContentProtection、AES-128 などの暗号化 HLS/DASH
- ライブ配信、`EXT-X-PLAYLIST-TYPE:EVENT` の継続中プレイリスト、DASH の `type="dynamic"`
- YouTube など、署名付き URL や独自プレイヤー処理が必要な配信
- 特殊なリクエストヘッダー、トークン、独自認証が必要な配信
- 再エンコード、形式変換、映像と音声の DASH 結合
- マニフェストに含まれない字幕、広告、代替音声の個別保存

MPEG-TS の HLS は H.264 / AAC を想定しています。HEVC や AC-3 など、ブラウザー側の変換器が扱えない組み合わせは保存に失敗することがあります。

## 設定

設定ページはポップアップ右上の歯車、または `chrome://extensions` の「拡張機能のオプション」から開きます。

| 設定 | 内容 |
| --- | --- |
| 保存フォルダー | Chrome のダウンロードフォルダー配下の保存先。既定は `MediaSaver`。`/` で階層を指定可能 |
| サイトごとのサブフォルダー | 例: `MediaSaver/example.com/title.mp4` |
| ファイル名テンプレート | `{title}` `{site}` `{date}` `{quality}` `{index}` `{host}`。拡張子は自動で付与 |
| 同時ダウンロード数 | 1〜6。超過分はキューで待機 |
| 最小サイズ | 一覧に表示する最小サイズ（MB）。サイズ不明のメディアは常に表示 |
| 検出する種類 | 動画 / 音声 / 画像の表示切り替え |
| テーマ | システム連動 / ライト / ダーク |
| 除外ドメイン | 指定ドメインとそのサブドメインを一覧から除外 |
| ダウンロード履歴 | 完了した履歴を消去。保存済みファイルは削除しない |

保存名が既に存在する場合は Chrome が連番を付けます（`conflictAction: uniquify`）。
完了・失敗・キャンセルしたダウンロード履歴は、ブラウザーのセッション内で新しい順に最大 60 件保持し、ブラウザーを再起動すると消えます。待機中・処理中のジョブは件数に関係なく保持します。設定は再起動後も保持されます。

## 権限

| 権限 | 用途 |
| --- | --- |
| `downloads` | 結合したファイルを Chrome のダウンロードに渡すため |
| `storage` / `unlimitedStorage` | 設定、タブごとの検出結果、履歴、一時ファイル（OPFS）の保存 |
| `webRequest` + `<all_urls>` | 任意のサイトで HLS / DASH / 直接ファイルの通信を検出するため |
| `scripting` / `tabs` | ユーザーがポップアップを開いたときにページ内をスキャンし、タブ情報とバッジを更新するため |
| `offscreen` | HLS / DASH の結合と保存用 Blob の生成を、画面のない拡張機能ページで行うため |
| `alarms` | サービスワーカーが休止しても、待機中のジョブを再開するため |

`<all_urls>` は、任意のサイトのメディアを検出・取得するために必要です。特定ドメインだけに限定することはできません。
権限を追加する変更を行う場合は、この表と `manifest.json` を同時に更新してください。

## プライバシーとセキュリティ

- 検出した URL、ページ内容、Cookie の値を外部サーバーへ送信しません。分析・トラッキングもありません。
- メディアの取得は元の配信サーバーへ直接行います。既存のログイン状態を使うため Cookie を伴う通常のリクエストを送りますが、Cookie を読み取ったり保存・転送したりはしません。
- 公開ページからプライベート IP（localhost、社内ネットワークなど）を読みに行くSSRFを防ぐため、保存対象だけでなく、HLS / DASH のマニフェストに書かれた URL とリダイレクト先も同じ基準で検証します。
  - マニフェストに書かれたプライベートな URL には、リクエストを送りません。
  - リダイレクト先は fetch の仕様上、送信した後でしか分かりません。そのリクエストは送られますが、応答は読まずに失敗させます。
  - 判定はホスト名と IP アドレスの表記で行います。プライベート IP に解決される公開ドメイン名は判定できません。
- ファイル名と保存フォルダーはサニタイズし、パス traversal や予約名を防ぎます。
- 外部ページからのメッセージは受け付けず、拡張機能自身のページとオフスクリーン文書だけを信用します。
- 保存用 Blob URL はダウンロード完了または失敗後に解放します。

## ファイル構成

```
media-saver/
├── manifest.json
├── background.js          # 検出、タブ状態、ジョブキュー、ダウンロード
├── content.js             # オンデマンドの DOM スキャン
├── offscreen.html/js      # 取得、HLS/DASH 結合、OPFS、Blob 生成
├── popup.html/js          # メディア一覧、画質選択、ダウンロード履歴
├── options.html/js        # 設定、除外ドメイン
├── ui.css                 # ポップアップ / 設定のスタイル
├── lib/
│   ├── common.js          # 分類、設定、ファイル名、SSRF 判定
│   ├── hls.js             # HLS パーサー、TS→MP4、fMP4 連結
│   ├── dash.js            # MPD パーサー、セグメント展開
│   └── mp4.js             # MP4 サンプルテーブル生成
├── vendor/
│   ├── mux.min.js         # mux.js（Apache-2.0）
│   └── mux.js-LICENSE
├── icons/
└── tests/                 # 単体テスト、実ブラウザー統合テスト、fixtures
```

ビルド手順はありません。プレーンな JavaScript と Manifest V3 のまま読み込めます。
アイコンは `tools/make-icons.cjs` で生成しています。

## テスト

```bash
cd media-saver

# 単体テスト（44 件）
node --test tests/*.test.cjs

# 実ブラウザー統合テスト（20 チェック）
PLAYWRIGHT_MODULE=/path/to/node_modules/playwright node tests/browser.cjs
```

- 単体テストは実際に ffmpeg で生成した HLS / DASH の fixture を使います。`ffprobe` がある場合は、生成した MP4/M4A のストリーム構成も検証します。
- ブラウザーテストは Playwright の Chromium に未パッケージ拡張機能を読み込み、ローカル HTTP サーバー上の fixture で検出、ポップアップ、画質取得、HLS 結合、直接ダウンロード、DASH の2ファイル保存、設定を確認します。
- 同じサーバーを `public.test` という名前でも読み込み、公開ページとして扱います。この公開ページで、マニフェストとリダイレクトがプライベートアドレス（127.0.0.1）を指す場合の拒否を確認します。
- 300件を超える一括保存の拒否、110件のジョブの完了、未完了ジョブの永続化、完了履歴の60件への整理も確認します。
- 別の場所へリダイレクトされた HLS / DASH のマニフェストが、最終的な URL を基準に画質取得・保存できることを確認します。
- Chrome がダウンロードを開始している最中にキャンセルしたとき、そのダウンロードを止め、次のファイルを保存しないことを確認します。
- サービスワーカーを実際に停止して再起動させます。次の2つの DASH ジョブを対象に確認します。
  - 片方の出力だけ失敗したジョブ
  - 1本目の出力だけ記録されたジョブ
- これらが「失敗」になり、実行中のダウンロードを止めてファイルを解放し、後ろに並んだジョブが処理されることを確認します。
- Playwright はこのリポジトリの依存関係ではありません。`PLAYWRIGHT_MODULE` にインストール済みの `playwright` ディレクトリを指定してください。
- テストのスクリーンショットは `test-results/` に出力され、Git の対象外です。

## トラブルシューティング

| 症状 | 確認すること |
| --- | --- |
| メディアが表示されない | 動画を再生する、ページを再読み込みして再スキャンする。`chrome://` など保護されたページではスキャン不可 |
| HLS / DASH が出ない | プレイヤーがマニフェストを要求するまで再生を進める。インストール後はページも再読み込みする |
| 保存に失敗する | ログイン切れ、URL の期限切れ、DRM、ライブ配信、分離 fMP4 HLS、特殊ヘッダー要求でないか確認する |
| 音声が出ない / 再生できない | 元のコーデックがブラウザーで再生可能か確認する。再エンコードは行わない |
| 保存先が分からない | Chrome のダウンロードフォルダー配下の `MediaSaver/<host>/` を確認する |
| 履歴が消えた | ダウンロード履歴はブラウザーセッション内のみ。保存済みファイルは残る |

## クリーンルームとライセンス

本拡張機能は、公開されている Web 標準（RFC 8216 HLS、ISO/IEC 23009-1 DASH、ISO BMFF）と、独立して作成したコードに基づく実装です。
特定の既存拡張機能のソースコード、難読化コード、UI デザイン、画像を複製していません。

HLS の MPEG-TS 変換には [mux.js](https://github.com/videojs/mux.js) を vendoring しています。mux.js は Apache License 2.0 で提供され、ライセンス全文は `vendor/mux.js-LICENSE` にあります。
