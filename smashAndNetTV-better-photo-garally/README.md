# SMASH and NET. TV Photo Gallery Plus

`https://www.smash-net.tv/photo/` のフォトギャラリーを使いやすくする Chrome 拡張機能です。

## 機能

- `←` / `→` キーで前後の写真へ移動
- `Esc` キー、または画像と操作ボタン以外の場所をクリックして閉じる
- `D` キーで表示中の写真をダウンロード
- 表示中の写真が現在のページ内で何枚目かを `現在番号 / ページ内画像数` で表示
- 表示中の写真の大会名（タイトル）と選手名など（サブタイトル）を画像下に表示
- モーダル右上のダウンロードアイコンから、ページを離れずに表示中の写真をダウンロード
- 元画像を再圧縮せず、画面内で可能な限り大きく表示（縦横比と原寸を維持）
- 一覧画像のフェードイン演出を無効化して即時表示
- 現在ページ前後、全体の中間地点、任意ページ選択を備えたページネーション

## インストール

1. Chrome で `chrome://extensions/` を開く
2. 右上の「デベロッパー モード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」を選ぶ
4. このフォルダを指定する

インストール後、すでに写真ページを開いている場合はページを再読み込みしてください。

以前のバージョンを読み込んでいる場合は、`chrome://extensions/` にあるこの拡張の
再読み込みボタン（円形の矢印）を押してから、写真ページも再読み込みしてください。
