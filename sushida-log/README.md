# Sushida Log

寿司打の終了後に表示される X 共有テキストを検出し、結果を Chrome 拡張のローカルストレージへ保存するツールです。

## できること

- X 共有 URL の `text` から結果を自動保存
- 検知した結果通信を Chrome のダウンロード先へ累積CSVとして自動保存
- 拡張ポップアップで履歴グラフを表示
- ポップアップに X 共有テキストを貼り付けて手動保存
- 保存済み結果を CSV / JSON でエクスポート

## 使い方

1. Chrome で `chrome://extensions/` を開きます。
2. 「デベロッパー モード」を有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」から、このリポジトリのフォルダを選びます。
4. `https://sushida.net/` で寿司打をプレイします。
5. 終了後、X 共有ボタンが生成またはクリックされると結果が保存されます。

自動検出できない場合は、X 共有テキストを拡張ポップアップの「手動保存」へ貼り付けて保存してください。

CSVへ自動保存するのは、X共有URLの共有テキストを取得できた場合だけです。`https://sushida.net/php/r.php` の通信値は、金額・速度・ミス数への対応が未確認のため、デフォルトではCSVに記録しません。

また、Unity 内部の共有処理候補を自動呼び出しし、X共有URLが生成された場合は X画面を開かずに共有テキストだけを保存します。

通常の保存先は以下です。

```text
~/Downloads/sushida-log/
```

## 対応している共有テキスト例

```text
高級10,000円コース【普通】
★7,700円分 お得でした！（速度：5.9key/秒、ミス：18key）
https://sushida.net/ #寿司打
```

## 注意

寿司打公式ページには「外部ツールの使用や、営利目的の使用は禁止」と記載されています。本ツールは入力の自動化やスコア操作を行わず、終了後の共有テキスト保存だけを目的にしています。
