## ローカルでの読み込み

1. Chrome で `chrome://extensions` を開きます。
2. 「デベロッパー モード」を有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」を選びます。
4. 使用する拡張機能のディレクトリを指定します。

各拡張機能の詳細や開発方法は、それぞれのディレクトリ内の README を参照してください。
