## 保存情報の照合エラーについて

旧コードでは、日本語の濁点などを NFC と NFD の異なる内部表現にすると、同じ保存先でも `DOWNLOAD_MISMATCH` となることを単体テストと実 Chrome で再現しました。照合時の正規化を追加しています。Unicode の互換変換で異なるファイル名まで同じ扱いにしないよう、照合には NFC を使用しています。

ご指定作品の全 91 枚は、旧コードを使った専用の新規 Chrome プロファイルでも保存できました。したがって、利用中の環境で今回のエラーが発生した原因が Unicode 表現であるか、別の拡張機能や保存設定の影響であるかは**未確認**です。WebP 形式が原因で保存できない挙動は、この検証環境では確認していません。

指定外の保存先へ変更された場合は `SAVE_PATH_CHANGED` として画面に原因を案内し、そのファイルは削除しません。他の拡張機能の指定が Chrome の仕様により優先される場合は、そちらの保存先変更設定を解除して再試行する必要があります。

## 作品ごとの画像抽出エラーについて

サイトの作品情報表で総枚数が空欄となる作品と、実画像数とは異なる作品を確認しました。実作品 3 件で、表記 42／82／53 ページに対し実画像が 43／84／56 枚であり、続きの画像番号が表記枚数を超えた際に「漫画画像の情報が不正です。」を再現しました。

表記枚数を基準とした処理を修正し、明示されたページ案内の範囲と同作品のリンクを検証して総枚数を取得します。正しい根拠のない画像枚数の推測では補完しません。数字付き案内のない旧形式の対応と、欠落・重複・別作品・不正なリンクの拒否は継続しています。
