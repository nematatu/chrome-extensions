# My Tools 管理画面

## 対象

共通の `popup.html` をポップアップと設定タブで共有します。管理RPCの送信元URL、19機能の登録、保存領域、ダウンロード処理は変更しません。各機能の元のポップアップはiframeで開き、専用の設定ページがある場合はそのページを新しいタブで開きます。

画面の状態は、選択中の画面、検索語、ワーカーから取得した設定・通知・保存履歴件数、処理中の状態と結果で表します。設定の正本は既存ワーカーです。画面独自の永続設定は増やしません。

## 参照と採用

2026-10-24に下記の公開ページを読み、Kumo、Radix、Fluid Functionalismの画面をブラウザーで確認しました。利用者数や評価の比較はしていません。

| 一次情報 | 採用した構造・操作 |
| --- | --- |
| [Kumo Switch](https://kumo-ui.com/components/switch/) | 名称とスイッチを同じ行へ配置。細い区切りと余白による整理。 |
| [Radix Playground](https://www.radix-ui.com/themes/playground) | 中立色を基本にした階層、必要な操作だけへのアクセント。 |
| [Radix Colorsの用途](https://www.radix-ui.com/colors/docs/palette-composition/understanding-the-scale) | 1〜2を背景、3〜5を操作状態、6〜8を境界・フォーカス、9〜10を強調、11〜12を文字へ対応。 |
| [Fluid Functionalism Switch](https://www.fluidfunctionalism.com/docs/switch) | コンパクトなスイッチとラベルの整列。装飾アニメーションは採用しません。 |
| [スロップ表現100連発](https://zenn.dev/todesking/articles/5bc43f449ecdf6) | 抽象的な標語、冗長な説明、装飾的な見出しを避ける文案の点検。 |

幅の狭いポップアップでも同じ操作を保てる「一覧とバックアップのタブ」を採用しました。サイドバーと常設の詳細ペインは、設定画面を持たない機能のために空の説明領域が必要になるため採用しません。

## 実装

スイッチとタブのキーボード・ARIA処理はRadixを再利用します。通常のボタンとファイル選択はHTML標準を使います。アイコンはLucideへ統一します。Reactは1バージョンとし、共有するRadix依存もnpmで重複排除します。

KumoはBase UIを基盤に持ち、別のアイコン集・チャート・構文表示の依存も要求するため、本体は追加せず画面の参照に使います。Fluid Functionalismも別の基盤を重ねず、操作の参照に使います。ドラッグ、分割パネル、アニメーション、追加の状態管理ライブラリは、現在の操作で必要がないため追加しません。

管理画面の文字サイズは12・14・20px、境界は0.5pxです。説明は操作時の結果とバックアップ範囲の注意に限定し、通常時の常設成功メッセージや行ごとの機能説明を取り除きます。色はRadix Colorsのトークンへ集約し、OSのライト・ダーク設定に追従します。

## 確認方法

`npm ci --prefix unified-tools`、`node unified-tools/build.mjs`、`node --test unified-tools/tests/*.test.cjs` を実行します。ブラウザーでの確認はREADMEの隔離Chromiumテストを使います。狭幅と広幅、ライトとダーク、タブのキーボード操作、19機能の切り替え、11個別画面、保存とJSON移行を確認します。Media Saver はフレーム内の狭幅表示、専用設定タブ、HLS/DASH処理を含めて確認します。

固定幅のタブ検証では実ポップアップの自動サイズを確認できなかったため、`tests/native-popup.cjs` を追加しました。幅の不具合は隔離した実ポップアップで55pxまで縮むことを再現し、HTMLの最小幅指定で解消しました。修正後は利用中Chromeのアイコンからも正常表示を確認しています。commit、push、外部へのデプロイは行っていません。

## 単独版とサイト内UI

全19拡張のpopup/options、注入ボタン、進捗、画像・漫画ビューアも共有の配色・アイコンへ揃えます。[共有UI](../shared-ui/README.md)に生成方法、参照、検証範囲をまとめています。共有資材を変更した場合は `node shared-ui/build.mjs` を先に実行してからMy Toolsをビルドします。

## better-ig

2026-10-28にInstagram保存と高画質表示を1項目へ統合しました。全体は19機能となり、共通の設定画面へ保存・高画質表示・Live横向き表示を配置します。既存のRadix配色とラベル付き標準コントロールを再利用し、別のUI基盤は追加しません。内部IDと保存履歴の形式は維持します。
