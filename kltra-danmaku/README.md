# KLTRA 弾幕チャット

KLTRATV の [galaxy 配信ページ](https://kltratv13.blogspot.com/p/galaxy.html)で、Cbox チャットの新着投稿を動画上に右から左へ流す Chrome 拡張機能です。無料のオンライン翻訳、または Chrome 内蔵の端末内翻訳で、日本語の弾幕に更新できます。

## Chrome への追加

1. Chrome で `chrome://extensions` を開き、デベロッパー モードを有効にします。
2. 「パッケージ化されていない拡張機能を読み込む」から、この `kltra-danmaku` フォルダを選びます。
3. 開いていた galaxy 配信ページを再読み込みします。拡張機能を更新した後も、タブを再読み込みしてください。

拡張機能のアイコンを押すと、設定ポップアップが開きます。配信画面上には操作ボタンを置きません。

## ポップアップの設定

- 弾幕を表示: ON/OFF（初期値 ON）
- 文字サイズ: 14〜40 px（初期値 23 px）
- 透明度: 0〜100%（初期値 0%。0% は不透明、100% は透明）
- 表示位置: 上寄せ 0%〜下寄せ 100%（初期値 0%）。複数の弾幕を流す帯の縦位置を変えます。
- 流れる速度: 60〜300 px/秒（初期値 130 px/秒）
- ユーザー名を表示: ON/OFF（初期値 ON）。OFF では本文だけを流します。
- 日本語に翻訳: ON/OFF（初期値 ON）。翻訳が終わってから日本語の弾幕を流します。翻訳に失敗した場合は最大3.5秒待って原文を流します。ユーザー名は翻訳しません。ステッカーだけの投稿は待たずに流します。
- 翻訳方式: 「オンライン翻訳（無料）」（初期値）／「端末内（Chrome 内蔵）」。オンライン方式では投稿本文だけを Google 翻訳へ送ります。ステッカーとユーザー名は送りません。端末内方式は投稿本文を外部に送らず、初回にモデルの取得が必要です。
- チャットの言語: 自動判定／インドネシア語／英語（初期値は自動判定）。オンライン方式では Google 翻訳に言語判定を任せます。端末内方式では Chrome の言語判定モデルが準備できるまではインドネシア語として扱い、準備後に確信度が低い短文は原文を残します。
- 翻訳を準備: 端末内方式で初回に押して、Chrome 内蔵モデルの取得完了を待ちます。取得後も翻訳が始まらない場合は配信ページを一度クリックしてください。自動判定ではインドネシア語、英語、言語判定の各モデルを順に準備します。オンライン方式ではこの操作は不要です。
- 弾幕付き全画面: 動画枠と弾幕を一緒に全画面表示します。終了するときは `Esc` を押します。

設定は Chrome のローカルストレージに保存されます。文字サイズ・透明度・ON/OFF は表示中の弾幕にも反映され、位置・速度・ユーザー名は次の投稿から反映されます。スライダーはつまみを離したときに保存されます。

## 動作と制約

- ページに埋め込まれた Cbox (`www3.cbox.ws`) を、チャットタブを開いていなくても読み込みます。新着投稿だけを表示し、読み込み時の過去ログは流しません。
- ユーザー名表示が ON の場合は投稿者名と本文を表示します。Cbox の絵文字ボタンで選ぶステッカー（`:数値:` などのコード）を、Cbox が返すステッカー画像とともに弾幕へ表示します。１投稿につき最大３枚です。任意の画像 URL や画像ファイルの直リンクは取り込みません。混雑時は重なりを避けるため、一部の投稿を画面表示から省きます。元のチャット欄には残ります。
- ステッカー画像は Cbox の `cbox.im` または `*.cbox.ws` 配下だけを受け付けます。投稿本文に未知のコードが含まれる場合は、その文字列をそのまま表示します。
- 動画プレイヤー自身の全画面ボタンで iframe だけを全画面にした場合、弾幕は見えません。ポップアップの「弾幕付き全画面」を使ってください。
- オンライン方式は Google 翻訳のウェブ用経路を利用します。API キーや支払い設定は不要で、拡張機能から料金が発生する仕組みはありません。この経路は公式の開発者向け API ではありません。[Google Developer Forums の回答](https://discuss.google.dev/t/translate-googleapis-com-translate-a/126639)は同種の非公式経路の利用を強く非推奨としており、利用制限や停止の可能性があります。接続失敗、応答遅延、翻訳失敗時は原文の弾幕を残します。原文は URL のクエリとして Google に送信されます。訳の精度は保証されません。
- オンライン方式は、実例の `China pless kamu bisa` を応援表現として `China, semangat! Kamu pasti bisa!` に補正してから翻訳します。同型の `pls`、`plz`、`please` も補正します。ほかの綴り違いや文脈までは補正できません。最大３件を並行翻訳します。日本語だけの投稿は翻訳しません。
- 端末内方式にはデスクトップ版 Chrome 138 以降の Translator API と、言語の自動判定には Language Detector API を使います。初回はモデル取得が必要です。端末内方式の自動判定が対応する元言語はインドネシア語と英語です。
- 大量のチャットでは処理待ちを制限し、画面から消えた弾幕は更新しません。
- Cbox の埋め込み先、投稿 DOM、または配信ページの動画枠が変更された場合は対応が必要です。チャットの読み込みに失敗した場合は投稿が表示されません。
- `storage` 権限は設定の端末内保存に使います。`https://translate.googleapis.com/*` の `host_permissions` はオンライン翻訳をサービスワーカーから呼ぶために必要です。指定した配信ページと Cbox iframe にだけコンテンツスクリプトを注入します。

## 開発時の検証

`node --test tests/*.test.js` でチャット取り込みと翻訳処理を確認できます。Node.js 22 以降と [Chrome for Testing](https://googlechromelabs.github.io/chrome-for-testing/) がある場合、次のコマンドで実サイト上の通しテストを実行できます。

```sh
CHROME_BIN="/path/to/Google Chrome for Testing" node tests/browser-e2e.mjs
```

通しテストは Cbox に投稿しません。読み込んだ iframe の DOM に検証用の投稿を追加し、移動、ステッカー表示、設定反映、全画面を確認します。開発者ツール接続のため、テスト中だけサイトの開発者ツール検出スクリプトを止めます。自然投稿の内容やステッカー一覧は配信状況に依存するため、固定の検証用 DOM で確認します。

`KLTRA_TRANSLATION_E2E=1` を付けると、Chrome の初回モデル取得と日本語弾幕への更新も試します。モデル取得には実際の Chrome の配布サービスへの接続が必要で、完了まで時間がかかることがあります。取得に失敗した場合は成功とは扱いません。

`KLTRA_MOCK_TRANSLATION_E2E=1` を付けると、翻訳モデルの代わりにテスト用の結果を返し、実サイト上でポップアップの操作と移動中の弾幕更新を確認します。このテストは実モデルの翻訳品質や取得成功を証明するものではありません。

`KLTRA_ONLINE_TRANSLATION_E2E=1` を付けると、実サイトで `China pless kamu bisa` をテスト用投稿として iframe の DOM に追加し、オンライン翻訳の応答が日本語の弾幕に反映されることを確認します。Cbox には投稿しません。
