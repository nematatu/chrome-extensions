# Google Photos Album Sorter

Googleフォトの写真プレビュー画面で、キーボードだけでアルバム追加を進めやすくする Chrome 拡張です。

## できること

- Googleフォト上に小さな設定パネルを表示します。
- Google Photos Toolkit と同じ非公式の Googleフォト内部RPCを使い、アルバム候補を取得します。
- 写真プレビュー中に `1` から `9`、`0` を押すと、新しい順上位10件の対応アルバムへ追加します。
- `Q` で直前に使ったアルバムへ再度追加できます。
- `Shift+A` でパネルを開閉できます。
- パネル右上の更新ボタンでアルバム候補を再取得できます。

## インストール

1. Chrome で `chrome://extensions/` を開きます。
2. 右上の「デベロッパー モード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」を押します。
4. このリポジトリのフォルダを選択します。
5. `https://photos.google.com/` を開き直します。

## 使い方

1. Googleフォトを開きます。
2. 写真をプレビュー表示します。
3. 拡張が自動でアルバム候補を取得します。
4. 矢印キーで写真を見ながら、新しい順上位10件に対応した `1` から `9`、`0` を押します。
5. 同じアルバムへ連続で仕分けたい場合は `Q` を押します。

10件目のアルバムは `0` キーです。
アルバム候補が出ない場合は、一度 Googleフォトのアルバム一覧ページを開くと、表示されているアルバムから自動で学習します。

## 注意

この拡張は Googleフォトの公開APIではなく、GoogleフォトWeb版の内部RPCを使います。Google Photos Toolkit の実装を参考にしていますが、Google公式のAPIではないため、Googleフォト側の変更で動作しなくなる可能性があります。

内部RPCが失敗した場合は、従来どおり画面上の「アルバムに追加」ダイアログから候補抽出を試します。
