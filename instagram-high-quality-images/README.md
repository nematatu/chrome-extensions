# Instagram High Quality Images

Instagramの投稿画像について、`srcset` 内でページが配信している最大サイズのURLを選び、表示画像へ適用するChrome/Edge向け拡張機能です。Instagram Liveでは、縦長の動画を自動判定して90度回転し、横向きに表示できます。

プロフィール一覧から投稿を開いた場合は、ログイン中のInstagram画像情報から最大候補を取得します。
元画像の縦横比を維持し、画面内にはクロップせず全体を表示します。

表示中の投稿画像にはシンプルなダウンロードアイコンが付きます。クリックすると、`instagram_ユーザー名_投稿ID_連番.jpg`というファイル名で既定のダウンロードフォルダーへ保存します。

Liveの横向き表示は、拡張機能ポップアップの「インスタLiveを横向き表示」から切り替えられます。`/live/` を含むInstagram Liveページと、Live由来であることを確認できるアーカイブ動画が対象です。いずれも縦長と判定できる動画のみを回転します。

## インストール

1. Chromeで `chrome://extensions` を開きます。
2. 右上の「デベロッパー モード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」を押します。
4. ダウンロードしたこのリポジトリのフォルダーを選択します。
5. すでに開いているInstagramのタブを再読み込みします。

Edgeでは `edge://extensions` から同様に読み込めます。

## 仕様上の制約

- Instagramがページ内で配信している候補より高い解像度にはできません。
- Instagram CDNの署名付きURLに含まれる圧縮指定は変更できません。
- 投稿画像のみを対象とし、プロフィール画像やナビゲーション内の画像は対象外です。
- Liveの横向き表示は、Instagramが動画の縦横サイズをブラウザーへ通知した後に適用されます。
- Instagram側の仕様変更により、将来調整が必要になる可能性があります。
