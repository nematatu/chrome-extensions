# Instagram High Quality Images

Instagramの高画質表示と、画像・動画の保存を行うChrome拡張機能です。既存の「最大解像度で表示」「縦長のInstagram Liveを横向き表示」も引き続き利用できます。

## 保存機能

- **画像・動画1件:** 投稿詳細で現在表示されているメディアだけに表示される右上のダウンロードアイコンを押します。画像は配信元の形式、動画はMP4で保存します。カルーセルの次のインデックスのメディアにはアイコンを表示しません。
- **投稿全体:** Instagram標準の保存（ブックマーク）ボタンの左にあるダウンロードアイコンを押します。カルーセルの未表示画像・動画も対象です。投稿詳細の個別アイコンとは同じ保存UIに統合されています。
- **ストーリー:** 既存のストーリー操作列の左側にあるアイコンで1件保存、その横の「一括保存」でそのアカウントの閲覧可能なストーリーをまとめて保存します。ハイライト内の保存にも対応します。
- **アカウント全体:** プロフィールのフォロー・メッセージ操作の上段にある「全投稿を保存」を押します。投稿一覧の各タイルにマウスを重ねると、いいね数・コメント数と投稿一括保存アイコンを表示します。投稿一覧を最後まで取得し、リール一覧も取得して、同じメディアを重複保存しないようにします。

保存を開始するたび、右下に独立したToastifyトーストが積み上がります。各トーストに保存件数、パーセンテージ、プログレスバー、個別停止ボタンを表示します。複数の投稿を続けて押しても各ジョブをすぐ開始し、ジョブ内は最大4ファイル、全体では最大16ファイルを並列保存します。完了したトーストは自動で消え、停止しても保存済みファイルは残ります。

## 保存先・形式

Chromeで設定しているダウンロード先に、次のフォルダを自動作成します。

```text
Instagram-High-Quality/
  アカウント名_投稿ID_01.jpg
  アカウント名_投稿ID_02.mp4
  アカウント名_ストーリーID_01.jpg
```

画像は変換せず、Instagram CDNが配信している元形式のまま保存します。動画は取得できる最大解像度のMP4を再エンコードせず保存します。アカウント別・投稿別のサブディレクトリは作りません。同名ファイルは上書きせず、Chromeが別名を付けます。

## インストール・更新

1. Chromeの `chrome://extensions` でデベロッパーモードを有効にします。
2. 「パッケージ化されていない拡張機能を読み込む」で、この `instagram-high-quality-images` フォルダを選びます。
3. Instagramのタブを再読み込みします。

更新時は拡張機能の更新ボタンを押してから、Instagramのタブも再読み込みしてください。Chrome 116以降が必要です。Edgeでは `edge://extensions` を使用します。

## 取得範囲と制約

- Instagramへログインし、対象の投稿・ストーリーを閲覧できる状態で使用してください。処理中はInstagramのタブを閉じないでください。
- 投稿一覧とリール一覧が対象です。タグ付けされた他人の投稿、保存済みコレクション、期限切れストーリーはアカウント全体の保存に含めません。
- 投稿一括保存とアカウント全件保存は、ログイン済みのInstagramページから投稿APIを呼びます。アカウント保存は投稿とリールを最後のページまでカーソルで取得し、画面を自動スクロールしません。
- ストーリー保存は追加のストーリーAPIを呼ばず、現在のストーリービューアーが読み込んだ同じアカウントのデータだけを使用します。「一括保存」に通常投稿やリールは含めません。
- 件数の多いアカウントは、APIの全ページ取得に時間がかかることがあります。停止後に再実行すると既存ファイルが別名で追加されることがあります。
- 配信中のLiveや、MP4を取得できない動画の変換・録画は対象外です。動画の代わりにサムネイルを保存することはありません。
`downloads` は保存、`offscreen` は一括保存処理の継続、`storage` は設定と進捗の保持に使用します。InstagramとInstagram配信CDN（cdninstagram.com／fbcdn.net）へのアクセス権限を使用します。

## 検証

```sh
node --test quality-core.test.cjs tests/*.test.cjs
```

ブラウザー統合テストは、Instagramの投稿API、ページングされたプロフィール投稿とリール、ストーリー画面が受信するデータ、画像・動画配信を再現します。

```sh
npm install
npx playwright install chromium
npm run test:browser
```

画像が変換されず元データのまま保存されること、保存先が単一ディレクトリであること、MP4の内容、投稿の未表示メディア、ストーリー対象の分離、APIの全ページ取得、自動スクロールを行わないこと、複数ジョブの並列実行、トーストの積み上げ、個別停止、重複排除を検証します。通常の使用にビルドやnpmは不要です。
