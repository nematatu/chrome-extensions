# 全国高体連バドミントン 写真送り修正

全国高等学校体育連盟バドミントン専門部サイトのフォトギャラリーを、
ページ上の並び順どおりに1枚ずつ表示する Chrome / Edge 向け拡張機能です。

大会IDや年度は固定していないため、同サイトの全年度・全大会ページに対応します。

## インストール

1. Chrome で `chrome://extensions/` を開きます。
2. 右上の「デベロッパー モード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」を押します。
4. この `koutairen-gallery-fix` フォルダーを選択します。
5. 対象サイトを再読み込みします。

Edge の場合は `edge://extensions/` から同様に読み込めます。

## 操作

- サムネイルをクリック：拡大表示
- 左右のボタン：前後へ1枚ずつ移動
- `←` / `→` キー：前後へ1枚ずつ移動
- スマートフォン：左右スワイプ
- `Esc` キー、背景、または右上の `×`：閉じる

最後の写真から次へ進むと最初に、最初の写真から前へ戻ると最後に移動します。
